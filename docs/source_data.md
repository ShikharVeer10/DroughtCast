# Data sources and provenance

This file records the current pipeline's data contract. The builder writes per-download NASA POWER response metadata beside the cached CSV. Older cached CSVs without that sidecar are marked unit-unverified; their values must not be described as API-metadata-verified.

| Input/target | Product and URL | Stored/expected units and resolution | Processing and known limits |
|---|---|---|---|
| Precipitation | NASA POWER monthly point, `PRECTOTCORR`; [parameter dictionary](https://power.larc.nasa.gov/docs/services/api/temporal/monthly/), [data FAQ](https://power.larc.nasa.gov/docs/faqs/data/) | Monthly temporal aggregate; API response units are checked and expected `mm/day` for community `AG` | Converted to monthly depth by multiplying the rate by calendar days. Monthly POWER data may be monthly averages; the code must not interpret it as an accumulated total. Daily fallback is aggregated only for full calendar months. |
| Temperature, dewpoint, wind, radiation, extrema | NASA POWER monthly point; `T2M`, `T2MDEW`, `WS10M`, `ALLSKY_SFC_SW_DWN`, `T2M_MAX`, `T2M_MIN` | Expected API units: °C, m/s, and daily radiation energy (reported metadata is recorded); monthly aggregates | Units are verified on fresh responses. Radiation is not used in the current Hargreaves–Samani PET formula. Monthly mean extrema do not recover daily temperature ranges. |
| Soil moisture | NASA POWER daily point; `GWETTOP`, `GWETROOT` | Daily unitless volumetric fraction/relative wetness, aggregated to month only with full daily coverage | Missing historical periods remain missing. No synthetic soil moisture is created. Confirm the NASA parameter dictionary and response metadata for the exact requested community before interpreting the scale physically. |
| PET and calculated SPEI | Derived from NASA POWER temperature and precipitation | PET is mm/month; water balance is mm/month; SPEI dimensionless | PET is monthly Hargreaves–Samani, **not** FAO-56 Penman–Monteith. It has not yet been validated against an independent PET product. SPEI is calibrated monthly through 2010-12. Calculated values outside the calibration range are not clipped to the calibration min/max, but the empirical score transform has a ±3.5 cap; tails therefore require sensitivity analysis. |
| ONI | NOAA CPC ONI [documentation and archive](https://www.cpc.ncep.noaa.gov/products/analysis_monitoring/enso/oni/v5/) | SST anomaly, °C; overlapping centered 3-month seasons | The source labels seasons by center month. Protocol lags two monthly rows conservatively. CPC notes recent ONI values can be revised; the raw table does not provide historical publication timestamps. |
| DMI | NOAA PSL monthly DMI [documentation](https://psl.noaa.gov/data/timeseries/month/DMI/) | °C; monthly HadISST-based index | One-month lag is a conservative proxy; actual historical release dates are not encoded in the source table. Citation: Saji et al. (2003), *Climate Research*, 25, 151–169. |
| NAO | NOAA PSL monthly NAO [data index](https://www.psl.noaa.gov/site_index.html) | Monthly standardized index (source-specific) | One-month lag is a proxy; source observation/release dates are not encoded. Exact recipe/source variant must be fixed in a final methods section. |
| PDO | NOAA PSL PDO [overview and data](https://psl.noaa.gov/pdo/) | Monthly standardized index (source-specific) | One-month lag is a proxy; missing sentinels are rejected. The cached table's latest valid observation can be old, so the protocol bounds carried values to 12 months and marks age. |
| Reference SPEI | SPEIbase v2.11 [NetCDF archive](https://spei.csic.es/spei_database_2_11/nc/) | Monthly, 0.5° grid, dimensionless SPEI-3/6/12 | Validation uses nearest grid cell to each site coordinate. Existing local comparison is available for 1990–2024 only. It is not an independent validation of NASA POWER inputs or PET. Cite Beguería et al. (2014), *Journal of Climate*, 27, 3–11, doi:10.1175/JCLI-D-13-00096.1. |

## Retrieval and coverage records

The current local cache includes historical NASA POWER CSVs and NOAA text files. Some NASA POWER cache files predate per-response unit sidecars, so their original retrieval dates and API-reported units cannot be reconstructed from those CSVs alone. The current monthly table has 12 sites × 442 rows (January 1990–October 2026); this is the table's date coverage, not proof that every source variable is complete at every endpoint. Quality checks and source-by-site coverage must be regenerated from a fresh retrieval before paper submission. NOAA sources have heterogeneous update schedules; a one-month lag is not equivalent to verified publication availability.

Data products are provided by NASA and NOAA public data services; use their applicable data-use and citation guidance. SPEIbase citation is required when using its reference series. This repository does not currently contain source-specific license statements for every upstream input, so the dataset should not be redistributed under a blanket license without confirming each provider's terms.
